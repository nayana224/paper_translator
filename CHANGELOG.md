# Changelog

## 1.0.0

- PySide6 desktop 중심 구조를 browser-first web application으로 전환
- 하나의 Tailscale HTTPS 주소에서 Windows/Linux/Android 지원
- PDF.js viewer를 browser에 직접 통합
- PDF 파일을 server에 업로드하지 않고 browser memory에서 열도록 변경
- TranslateGemma streaming translation 추가
- Markdown rendering 유지
- Academic glossary를 server에서 중앙 관리
- 최근 번역 history를 browser localStorage에 유지
- GitHub 공개를 위한 setup/architecture/API/operations/development/security 문서 정리
